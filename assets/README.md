# assets

Drop real photos here. `index.html` references them and falls back to a
styled placeholder if a file is missing, so you can add them any time.

| filename | used for | ideal size |
| --- | --- | --- |
| `roastery.jpg` | About section image | ~1600×1200, landscape |

Add more later (branch interior, coffee bags, pour shots) and wire them
into the About/closing sections or a small gallery strip.
