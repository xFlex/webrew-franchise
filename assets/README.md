# assets

Drop real photos here. `index.html` references them and falls back to a
styled placeholder if a file is missing, so you can add them any time.

| filename | used for | ideal size |
| --- | --- | --- |
| `roastery.jpg` | About section image | ~1600×1200, landscape |
| `logo-icon.svg` | Header/footer icon mark (same in both languages) | square, transparent background, SVG preferred (PNG also works) |
| `logo-wordmark-ar.svg` | Header/footer wordmark, shown in Arabic mode | wide lockup, ~height 22px at 1x, transparent background |
| `logo-wordmark-en.svg` | Header/footer wordmark, shown in English mode | same as above, English "Webrew" logotype |

Until the logo files above exist, the header/footer show a plain "W"
badge and live "Webrew"/"ويبرو" text instead — drop the real files in
and they take over automatically, no code changes needed.

Add more later (branch interior, coffee bags, pour shots) and wire them
into the About/closing sections or a small gallery strip.
