# Webrew Roasters — Franchise Opportunity Page

Backup of the Webrew Roasters franchise-opportunity landing page.

- **Built with:** Claude Design
- **Deployed on:** Netlify — <https://webrew-coffee-roasters-franchise-opportu-cd-ebecebed10.netlify.app>
- **Claude Design project:** `74a168f5-6542-4744-8d84-a4351c4c1a8f` (`Webrew Franchise.dc.html`)

## Contents

| File | Description |
| --- | --- |
| `index.html` | The deployed page as served by Netlify — a single self-contained bundle with all CSS, fonts, images and scripts inlined (~3.4 MB). This is the **rendered output**, not the editable Claude Design source. |

## Restoring / editing

The editable source is the `.dc.html` canvas file in the Claude Design project above.
To add it to this repo, authorize Claude Design access (`/design-login` in the
Claude Code CLI) and export `Webrew Franchise.dc.html` plus its `_ds/` design-system
bundle, then commit them alongside `index.html`.
